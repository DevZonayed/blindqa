# Getting help

- **How do I…? / Is this a bug?** — start a thread in
  [Discussions → Q&A](https://github.com/DevZonayed/blindqa/discussions). Include `blindqa doctor` output.
- **Something is broken** — [open a bug report](https://github.com/DevZonayed/blindqa/issues/new/choose).
- **blindqa reported a problem that isn't real** — use the "False finding" issue form.
- **Security issue** — privately, see [SECURITY.md](SECURITY.md).

Before asking, the docs answer most setup questions:
[Install](docs/INSTALL.md) · [Browsers per machine](docs/BROWSERS.md) · [The .blindqa folder](docs/LAYOUT.md) ·
[Re-testing changes](docs/RETEST.md) · [Costs](docs/COSTS.md).
